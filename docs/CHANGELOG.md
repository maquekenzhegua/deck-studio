# 更新记录

版本号只标「能不能用」，真正的变化写在条目里。每条都能在仓库里找到对应提交。

## 0.9.4

- 增量桥按「先涨后跌」排序：+248 / +65 / +36 / +2 / −21 / −22，合计 308 万，读起来是一条阶梯而不是断掉的折线
- 计划提示词加两条骨架规则：六页以上必须有章节页、图表至少两种画法、结尾必须是行动页
- 事实清单区分（合计）（均值）（N 项），左栏不再出现两条同名数据
- 模型写的长标题在标点处收到 26 字以内；要点最多 4 条

## 0.9.3

- 结构上加第二张章节页：前半讲证据，后半讲取舍，15 页一镜到底的问题解决
- 章节页两位序号不再只显示第一位；目录取每章第一句
- 全自动：一次点击跑完「提角度 → 排页序 → 写讲稿 → 排版导预览」

## 0.9.2

- 标题换成真正能渲染的思源宋体 Heavy；缺字体时依次退到华文宋体、宋体
